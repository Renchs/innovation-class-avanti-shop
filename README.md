# Innovation Class - Avanti Shop

### 📝 Objetivo
O desafio final consiste em desenvolver um layout proposto no **Figma** utilizando **HTML, CSS e JavaScript.**
 
🔗 [Acesse o layout no Figma](https://www.figma.com/proto/DqtFxC6312M32mLt8FpJjq/innovation-class?page-id=13%3A673&node-id=13-920&viewport=346%2C140%2C0.11&t=HyGGDSs83f1vbqMJ-1&scaling=scale-down&content-scaling=fixed)

🔗 [Link do projeto](https://renchs.github.io/innovation-class-avanti-shop/)


### ✅ Requisitos para o desenvolvimento:

#### 1️⃣ Estruturar o HTML conforme o layout do Figma


#### 2️⃣ Aplicar estilos com CSS, garantindo um layout responsivo (Versão Desktop e Mobile no Figma)

Pode utilizar um framework CSS de sua escolha, como Bootstrap, Bulma ou outro

#### 3️⃣ Implementar uma funcionalidade de busca com JavaScript:

- No campo de busca, ao clicar no botão da lupa, o texto digitado no campo deve ser exibido abaixo com a mensagem: "Você buscou por: 'assunto buscado'"
- Implementar a interação dos carrrosséis. Pode ser através de biblioteca
